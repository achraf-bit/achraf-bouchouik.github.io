# assets/images/

Place all your portfolio images here and reference them in `data.yaml`.

## Recommended sizes

| Usage       | Size        | Aspect ratio |
|-------------|-------------|--------------|
| Profile     | 400 × 400   | 1:1          |
| Experience  | 800 × 500   | 16:10        |
| Projects    | 800 × 500   | 16:10        |
| Education   | 600 × 400   | 3:2          |

## Naming convention

```
profile.jpg
exp-<company>.jpg
proj-<name>.jpg
edu-<institution>.jpg
```

## Missing images

If a path in `data.yaml` is empty or the file doesn't exist, the site automatically
falls back to a neutral placeholder image from placehold.co — no broken image icons.
